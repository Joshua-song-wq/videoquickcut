# videoquickcut
This is a c# program to automize replacing certain interval of a video with image using Gyan.FFmpeg without directly typing complex command on powershell.
It will automatically use rtx series gpu if available.
It needs Gyan.FFmpeg, so install it using this command.
```powershell
winget install Gyan.FFmpeg
```
